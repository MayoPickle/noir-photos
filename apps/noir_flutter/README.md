# Noir Flutter Client

This directory contains the Flutter source for the iOS, Android, and Web clients. Native runner directories are intentionally generated by Flutter so they match the installed SDK.

## Bootstrap

```bash
flutter create . --platforms=ios,android,web
flutter pub get
dart run sodium:update_web --sumo
flutter run --dart-define=NOIR_API_URL=http://localhost:8000
```

## Native Permissions

After `flutter create`, add the following platform permissions.

Android `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32" />
<uses-permission android:name="android.permission.INTERNET" />
```

iOS `ios/Runner/Info.plist`:

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>Noir Photos encrypts selected library items before backup.</string>
<key>NSPhotoLibraryAddUsageDescription</key>
<string>Noir Photos can save restored encrypted photos back to your library.</string>
<key>BGTaskSchedulerPermittedIdentifiers</key>
<array>
  <string>noir.photos.backup</string>
</array>
```

Web requires `dart run sodium:update_web --sumo` so `SodiumSumoInit` can load libsodium.js before the Flutter app starts.
